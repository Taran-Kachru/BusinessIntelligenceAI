# KPI Pulse

> "KPI Pulse turns a KPI movement into a governed, evidence-cited, persona-aware explanation and a concrete recommended action — using deterministic statistics for every number and an LLM only for the words."


---

## LLM vs Non-LLM: What does what

**The architecture invariant: the LLM is never the source of quantitative truth.**
Every number visible in the UI was produced by a deterministic code path. The LLM only renders sentences.

| Capability | Who does it | Method / Tech |
|---|---|---|
| Anomaly detection | **Non-LLM** | Rolling Z-score (28-day window) + IsolationForest — `detect.py` |
| Dual materiality scoring | **Non-LLM** | `0.5 × (\|z\| / z_threshold) + 0.5 × (\|$impact\| / $threshold)` |
| PVM decomposition | **Non-LLM** | Algebraic price/volume/mix attribution (Revenue KPI only) — `drivers.py` |
| Driver ranking (non-Revenue) | **Non-LLM** | OLS regression, statsmodels explained-variance ranking — `drivers.py` |
| Qualitative driver lookup | **Non-LLM** | Rule lookup from `context_notes` table via DuckDB |
| Freshness tracking | **Non-LLM** | `MAX(date)` per table vs `DEMO_TODAY`, days-stale calculation — `reconcile.py` |
| Confidence score | **Non-LLM** | `0.5 × explained_var + 0.3 × freshness_factor + 0.2 × completeness` — `abstain.py` |
| Abstention decision | **Non-LLM** | 4 deterministic rules (low variance, contradictory drivers, overall < 0.4) |
| Row-level security (RLS) | **Non-LLM** | Region filter injected in `secure_query()` before any SQL executes |
| PII redaction | **Non-LLM** | Column-level mask applied in `secure_query()` — `database.py` |
| Evidence IDs (`[E001]`) | **Non-LLM** | Deterministic hash from `(kpi, period, source, method)` — `reconcile.py` |
| Feedback / weight overrides | **Non-LLM** | Multiplicative compounding, JSON persistence — `feedback.py` |
| Token / latency telemetry | **Non-LLM** | SHA256-keyed cache, instrumented wrapper — `telemetry.py` |
| Persona-specific narrative | **LLM (Gemini Flash)** | Prompt contains only pre-computed numbers + `[Exxx]` IDs; no quantities generated by LLM |
| Action card drafting | **LLM (Gemini Flash)** | Fixed lever catalog + decision-rights enforced *before* LLM sees the prompt |
| Free-text Q&A intent parse | **LLM (Gemini Flash)** | Extracts KPI + region + period; answer is computed deterministically, not by LLM |

## Stack

| Layer | Technology |
|---|---|
| Backend API | FastAPI + Uvicorn |
| Analytical engine | DuckDB (in-memory over CSVs) + pandas + numpy |
| Statistics / ML | statsmodels (OLS), scikit-learn (IsolationForest) |
| LLM | Google Gemini Flash (free tier) — `gemini-2.5-flash` |
| Frontend | React 18 + Vite + Tailwind CSS + Recharts |
| Tests | pytest — 85 tests, 0 warnings |

## Quick start

```bash
# 1. Generate synthetic data (already in data/)
python data/generate_data.py

# 2. Create venv and install
python -m venv venv
venv/Scripts/pip install -r requirements.txt     # Windows
# OR: venv/bin/pip install -r requirements.txt  # Linux/macOS

# 3. Configure
cp .env.example .env
# Edit .env:
#   GEMINI_API_KEY=your_key_here  (or set FALLBACK_MODE=true to skip LLM)
#   DEMO_TODAY=2026-08-18
#   FALLBACK_MODE=false

# 4. Start backend (from repo root)
venv/Scripts/python -m uvicorn backend.main:app --reload

# 5. Start frontend (separate terminal)
cd frontend && npm install && npm run dev

# 6. Open http://localhost:5173
```

## Demo scenarios

Four scenarios are baked into `data/generate_data.py`:

| # | Scenario | What to show |
|---|---|---|
| 1 | West Revenue drop Aug 11–17 | PVM decomposition: price −8%, volume −15% + qualitative competitor-promo driver |
| 2 | East Churn — stale data | Abstention fires: freshness penalty pushes confidence < 0.4, clarifying question shown |
| 3 | SKU-NEW sparse history | `method_fallback=True` → benchmark substituted, confidence downgraded |
| 4 | `customer_events` June refresh | Freshness panel shows STALE (73 days), penalty applied to confidence score |

## 5 KPIs · 3 sources · 2 personas

**KPIs**: Revenue, Units_Sold, AOV, Marketing_ROI, Churn_Rate

**Sources**: `sales_transactions` (daily grain), `marketing_spend` (weekly), `customer_events` (monthly / deliberately stale)

**Personas**:
- **CEO** — all regions, PII visible, full decision authority
- **Regional Manager West** — West region only, NPS comments redacted, limited lever authority

## Architecture

```
User request
    │
    ├─► secure_query() ──► DuckDB SQL ──► pandas / statsmodels / sklearn
    │                                              │
    │                                      deterministic numbers + [Exxx] IDs
    │                                              │
    └─► Gemini Flash ◄──── pre-computed evidence (numbers + IDs only)
                │
                └─► narrative text only (LLM never asked to produce a number)
```
